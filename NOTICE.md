# Notice

The USB probe kext (`src/usb/`) is GPL-2.0-only and contains code ported from the Linux kernel
`rtl8xxxu` driver (`drivers/net/wireless/realtek/rtl8xxxu/`, GPL-2.0-only, Copyright Jes Sorensen and
contributors): register constants, efuse read, power_on, firmware download sequence, and the MAC/BB/RF
init tables (generated by `scripts/gen-rtl8188eu-tables.py`, copied mechanically from `8188e.c`).

`rtl8188eufw.bin` is Realtek firmware from linux-firmware (`LICENCE.rtlwifi_firmware.txt`). It is fetched
by `scripts/fetch-rtl8188eu-fw.sh` and never committed to git. Prebuilt kext releases embed the unmodified blob
(binary form, license text `LICENCE.rtlwifi_firmware.txt` shipped in the zip, as that license requires). The source
tree and the generated header are not redistributed.

`src/usb/rtl8188eu_ra.h` is a port of the software rate adaptation in `8188e.c` (rtl8188e_rate_decision, power training,
TX report type 2 handling) and its tables; `src/usb/rtl8188eu_txdesc.h` ports `rtl8xxxu_fill_txdesc_v3` and `rtl8xxxu_queue_select`.
Both are GPL-2.0-only, derived from the Linux kernel `rtl8xxxu` driver (Copyright Jes Sorensen and contributors).

The integrated driver patches (`patches/`) apply to AirPort-RTW (GPL-2.0, derived from the Feixiao rtw88 macOS port and Linux rtw88).
